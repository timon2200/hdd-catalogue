Index your drives.
Find anything.

A macOS menu-bar app that scans your external drives, uses AI to categorize projects, detects duplicates, and keeps everything searchable — even when drives are offline.

⬇ Download for macOS View on GitHub

Built for creative professionals

Designed for video editors managing projects across dozens of external drives

🔍

Unified Search

Search across all projects, clips, and files — by name, codec, camera, visual tags, even AI descriptions. Works offline.

🤖

AI-Powered

100% local AI via Ollama with guided setup. Auto-detects cameras, categorizes projects, generates visual tags and descriptions. No data leaves your Mac.

📂

File Explorer

Three-panel file explorer with deep metadata — codec, resolution, frame rate, camera model, color space. Video scrubbing on hover.

🎨

LUT Preview

One-click LOG → Rec.709 conversion. Auto-selects the right LUT based on detected camera profile (S-Log3, D-Log M, etc.).

💾

Storage Intelligence

Dashboard with per-client storage breakdown, SSD/HDD tracking, archive suggestions, and side-by-side drive comparison.

🔄

Auto Updates

Install once — updates arrive automatically via Sparkle. Always on the latest version with zero effort.

📋

Smart Bins

Create dynamic project groups with custom filter criteria. New projects matching your rules appear automatically after scans.

🏷️

Tags & Status

Custom tags, status pipeline (New → In Progress → Review → Delivered → Archived), and per-project notes — all searchable.

📡

Offline Catalogue

All metadata persists locally via SwiftData. Browse and search your entire library even with every drive disconnected.

🔄 Auto-updates built in

Download once and you're set. HDD Catalogue checks for new versions automatically via Sparkle and prompts you to update — one click, no reinstall.
